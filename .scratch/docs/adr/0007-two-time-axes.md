# Calendar months for cash, fiscal years for tax

Status: accepted (2026-11-11).

Spending, budgets, Fixed Expenses and dashboard summaries use calendar months; the Tax module and annual income totals use the Bangladesh Fiscal Year (1 July to 30 June). The user budgets by month but is taxed by fiscal year, and blending the two in one aggregate produced wrong totals in the spreadsheets. For the same reason the dashboard and budgets use In-Hand Income while the Tax module uses Gross Income.
