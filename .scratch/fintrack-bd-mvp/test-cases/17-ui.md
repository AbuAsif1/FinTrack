> **Smoke** runs three E2E journeys: redirect-to-sign-in, adding a Transaction end-to-end, and the Tax Dashboard end-to-end. **Happy Path** covers all P1 UI component and E2E cases across every screen. **Full Regression** adds P2/P3 theme, focus-trap, filter, delete-confirmation, accessibility and analytics cases.
